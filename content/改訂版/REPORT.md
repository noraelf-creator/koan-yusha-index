# REPORT — こちら公安勇者パーティ（マダミス5）改訂

状態：**Phase 0〜7 完了（作者確認待ちあり）**

---

## 1. 作品の評価

**強み**
- 公安×勇者パーティ×テロ×異世界転生という、他に無い世界観。キャラクターが全員「変な人」で、台詞に勢いがある（ルキナの怠惰の屁理屈、ライトニングの闇墜ち美学、アベルの欲望むき出しの勇者、ウエスカーの黒塗り論争、ソフィーのTS愛）。
- 作者が決めた新しい真相（ロトは死を偽装、遺体は別人、バリーも生きている）が、**第一議論→第二議論→最終戦**の三段で裏返る。仮想プレイでは「ロトが死んだ」→「ロトじゃない」→「じゃあバリー？」→「ロトもバリーも出てきた！じゃああの死体は誰？」が狙いどおりに起きた。
- 旧版の文章（配布HO・ver2本文・GM資料）に、新しい真相を支える素材が多く残っていた（「上司が死んだことにしよう」「死体を用意した。本当はバリーでもよかった」「バリーは交渉に乗ってくれて何より」「今私は脅されてて」）。作者の構想が一貫していることが分かる。

**弱み（改訂前）**
- 新版は骨格・盤面の確認稿までで、遊べる配布物が無かった。電話の応答、調査のルール、投票、第三議論の資料、ロト再登場の台本が未確定。
- 旧版は事件と情報の同時処理が多く、読み合わせが長かった（作者自身の振り返り）。

## 2. 主な改善点

1. **遊べる一式を作った**：共通HO、PC別HO（事前①・ゲーム中②・電話③・記憶④・後半⑤・記憶⑥）、読み合わせR01〜R21、カード（共通資料C01〜C20・調査S01〜S17・第二議論N01〜N03・第三議論Y01〜Y06・投票用紙・推理の手引き）、GM進行ガイド。
2. **新真相の穴を、旧版の素材だけで埋めた**：遺体のすり替え（朝の搬入の「異臭の箱」）、窓の3回の通過、ロトの服の《認識変更》が遺体にも効く、バリー襲撃と交渉の時刻、脱出はカムイのトラック。新しい殺害方法・新しいNPC・新しい能力は足していない。
3. **アベルを「殺したと思い込んでいる」側にした**（作者確認待ち）：ウエスカー（逃がした相手を確かめていない）と対になり、二人の隠す側がどちらも第二議論で揺れる。
4. **GMの自由な演技を減らした**：密談と電話を、旧GM資料の台詞で固定してHO・カードに収録。
5. **仮想プレイ4回で見つけた問題を修正**：調査結果の全員公開、窓・ログの調査条件の引き下げ、推理の手引き、受付表の具体例、検問の証言、第三議論のおまけの問い（魔王の座にいるのは誰か）。
6. 読み合わせは地の文1〜2行＋会話。台詞は5人に39〜53行ずつ配分。カードは原則1〜3文。HOは全て一人称・心情ベース。
