## 1. ひとことで言うと

**公安の暗部「魔王軍」が仕組んだ“勇者処分”の芝居の裏で、上司ロトと野良エルフが「ロトの死」を偽装して逃げた。**
プレイヤーは第一議論で「ロト殺し」と「バリー脱走」を追い、第二議論で「その遺体はロトではない」と知らされる。最終戦でロトとバリーが生きて現れ、「じゃあ、あの死体は誰だったのか」が残る。

## 2. 舞台の裏側（物語が始まる前）

### 魔王軍の筋書き（バリー立案・ルキナ承認）
- 公安の暗部「魔王軍」は、表で裁けない裏切り者を処分する部署。長は**魔王＝ルキナ**。右腕は**黒騎士バリー**。
- 連続テロ（地下鉄爆破／情報漏洩／シンジュク暴動）は本来別々の事件。それを映画『ドラゴン・ファイファン・エムブレム（DFE）』に見立てて一続きの事件に仕立てた。
- 目的は、テロリストに公安情報を流した**アベルの処分**。“勇者”とは公安の符丁で「処分する者に与える綺麗な肩書」。アベルは最後にテロリストと相打ちになり、名誉の殉職をする筋書き。
- バリーは「異世界から転生した容疑者の男」を演じ、3日前から警察署に拘留されている。今日の段取り：勇者パーティと1人ずつ密談 → 自由時間 → ウエスカーがバリーを逃がす → バリーが残した予告状で全員を三つの場所へ誘い出す → そこで事件処理と勇者の処分。
- 現場の補助：**カムイ**（ルキナの妹）が配達員「ベレス」として搬入とトラック、**クラウド**（ライトニングの双子の弟）が監視員「ティーダ」として地下を担当。
- ルキナは企画書を読まずに承認した。寝坊もした。筋書きのうち「バリーと1人ずつ話す」以外はほぼ知らない。

### ロトと野良エルフの企み（裏の裏）
- 上司ロトは先代の“勇者”。一度処分されかけ、生き延びて魔王軍に忠誠を誓った……ことになっている。実際はテロ組織「金星のりんご農家」とも通じていた。
- 野良エルフ（前世の名はメルル）は「金星のりんご農家」の長。アベルの奴隷ハーレムの一人として命令に従うふりをしながら、命じられた「ロトへの接近」をきっかけに、ロトと手を組んだ。
- 二人の計画：**今日、警察署で「ロトは死んだ」ことにして、二人で消える。**
- そのための遺体が要る。野良エルフは今日より前に、身元の分からない男 **X** を殺していた（★時刻・場所・素性は設定しない）。Xの遺体は段ボールに詰められ、朝の搬入物に紛れ込ませた（★ロトが資材の一つとして手配。ベレスは中身を知らずに倉庫へ運んだ）。
- 「本当はバリーでもよかった」（旧ver2最終EDのロトの台詞）。逃げる途中のバリーを襲い、その体を使う手もあった。

## 3. 二つの事件の真相

### 事件A「ロトの死」——実際は偽装

| 誰が | 何をした |
|---|---|
| ロト | 10時前に一度署外へ出て、野良エルフを連れて戻った（★受付に記録が残らなかったのは、ロトの服のSSR《認識変更》を野良エルフが《コピー》したため）。10:30、アベルを会議室に呼び出し、内通を突きつけて「君は勇者として殉職する」と告げる。11:00、乱入した野良エルフとアベルに“負け”、死んだふりをする。 |
| 野良エルフ | 11:00「アベル様！お助けに参りました！」と会議室に入り、アベルとロトを倒す。ロトの服を脱がせて自分が着る（SSR《認識変更》で周囲からはロトにしか見えない）。アベルを脅して口止めし、「窓を壊して侵入者の線を残せ」「倉庫に武器がある」と言い、扉から出ていく（11:30に受付を「ロト」として通過）。 |
| アベル | **自分と野良エルフでロトを殺したと思い込んでいる。** 倉庫の武器（聖剣）とスキル《はやぶさ》で12:30に格子窓を内側から破壊。武器を現場に置いて立ち去る。このとき見た「ロトの体」は女性で、どこか見覚えがあった。 |
| ロト（12:30以後） | アベルが去った後に起き上がる（★野良エルフが脱いだ服を着る）。 |
| 野良エルフ（12:30以後） | 12:30〜13:00、壊れた窓から会議室へ戻る（**窓の通過1回目**）。ロトと合流。 |
| ロト＋野良エルフ | 12:30〜13:00、署内のトイレで変装して待機していたバリーを襲う（**逃走中のバリーを襲う**）。だがバリーとの**交渉が成立**し、殺さない（★取引の中身：互いの秘密を黙る／カムイのトラックの荷台に同乗させる）。 |
| 野良エルフ | 13:00〜13:30、ロトの服を着たまま倉庫へ行き、Xの入った段ボールを台車で会議室へ運ぶ（ライトニングが「ロトが会議室に入った気がした」のはこの時）。 |
| ロト＋野良エルフ | 会議室でロトの服をXに着せ、顔を潰して身元を分からなくする（**Xの死体をロトの死体として偽装**）。窓から出る（**通過2回目・3回目**）。野良エルフは神弓を会議室に残した（★侵入者の痕跡に見せるため）。台車は廊下へ戻した。 |
| ロト＋野良エルフ | 13:30〜14:00、駐車場のカムイのトラックの荷台に潜り込む。14:00、カムイの運転で敷地の外へ（**脱出**）。 |

- 14:00にアベルとウエスカーが見つけた遺体は**X**。ロトの服のSSR《認識変更》が遺体にも働き、見る者には「ロト」に見えた。遺体はうつ伏せで、二人は現場保存のため動かしていない。
- 第二議論の開始時、検死で服を脱がせると《認識変更》が解け、**ロトではない男性**（顔面損壊・身元不明・体格はロトに近い）だと分かる。
- **Xを殺したのは野良エルフ**。ただしXの殺害は今日の警察署の外の出来事で、プレイヤーが特定する対象ではない。

### 事件B「バリー脱走」——魔王軍の計画どおり

| 時刻 | ウエスカー | バリー |
|---|---|---|

| 12:00〜12:30 | 署内の倉庫で変装道具の箱を開ける。バリーは最後の言葉を残して変装（《認識阻害》）。受付を変装で抜けるには二人の知・魔を合わせる必要があり、魔のクールタイム明けを待つ | 倉庫で変装。署内のトイレで1時間ほど待機 |

- **ウエスカーが逃がしたのはバリー本人**。ただしウエスカーは、変装後のバリーの顔をはっきり見ておらず、声も聞いていない。「自分が連れ出した男が本当にバリーだったか」を確かめられない。
- カムイは輸送役。荷台に誰が何人乗ったかを確認していない。途中で荷台が空になったので「降りた」と思っている。
- 監視員クラウドは命令で眠ったふりをしていた（睡眠薬ではない）。ライトニングの差し入れは関係ない。

### おまけの事故「ソフィーの負傷」——推理対象ではない
- 12:00帯の冒頭、ルキナは敷地外のカフェから戻る途中、片手にフラペチーノ、妹からのLINEに気を取られて、駐車場でソフィーを車で轢いた（メルルを追って飛び出していたソフィー）。
- ルキナは妹カムイを呼ぶ。カムイは作戦中の負傷者として扱い、トラックの段ボールにソフィーを入れて現場を片付けた。救急を呼べば報告書と事情聴取で作戦が表に出る（★）。ルキナは「地下ならクラウドが見ててくれるし、そのうち起きるでしょ」。
- 12:30 カムイが台車で署内へ、階段はカムイが担いで地下へ。13:00 クラウドの案内で、既に割れていた鏡から取調室へ寝かせる（バリーはもういない）。ルキナは待機室で寝る。
- 14:00、ライトニングに起こされてソフィーが見つかると、ルキナはあっさり「轢いたの、私です」と認める。**議論開始時点で全員が知っている。**
- ソフィーは会話はできるが重症（調査・技能不可）。食堂の「りんご」を食べると回復して調査できる。記憶は第二議論の開始時に完全に戻る（事故の衝撃が最後のきっかけ）。

## 6. 第二議論でプレイヤーが合理的に辿り着く推理

1. 検死で「ロトではない男性」と分かる → ロトの死は偽装された？（**仮説1：ロトは生きている**）
2. 行方不明の男性はバリー。変装（認識阻害）で顔が分からない。体格も近い → **仮説2：死体はバリー**
3. それならウエスカーが連れ出した「変装した男」は誰？ ウエスカーも顔を見ていない → **仮説3・4：認識阻害による取り違え**
4. 13時に「ロトらしき誰か」が会議室に入った、窓は3回通られている、配達員が箱を倉庫へ運んだ → 「トイレで待つバリーが殺され、会議室へ運ばれ、ロトの服を着せられた。外へ出たのは別人」という筋が組める。

**作者の狙い**：第二議論の結論は「遺体はバリーかもしれない」でよい。実際は違うが、それは失点にしない。最終戦でロトとバリーが現れて初めて「じゃあ、あの死体は誰だった？」となる。

**別の正しい道**：アベルが「12時に倉庫に異臭のする未開封の箱があった」と明かし、倉庫に空の箱が4つあることと結び付けると、「遺体は最初から箱で運び込まれていた第三の誰か」に辿り着ける。これも正解扱い（Xの名前は誰にも分からない）。
